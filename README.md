# 🌹 RosePetal — Modern Task Management Application

RosePetal is a **feature-rich task management web application** designed to help users organize, track, and manage tasks efficiently with a clean and interactive user interface.

Built as part of my **Web Development Internship at VaultofCodes**, this project focuses on real-world usability, dynamic behavior, and responsive design.

## 🚀 Live Demo

🌐 modern-ui-todo-app-rosepetal.netlify.app

# 🛠 Tech Stack

- HTML  
- CSS  
- JavaScript  
- Tailwind CSS  
- Local Storage  

# ✨ Features

- ✅ Add, edit, and delete tasks  
- 🔄 Drag-and-drop task reordering  
- 🔍 Real-time search functionality  
- 🎯 Task filtering (All / Pending / Completed / Priority)  
- 🌙 Dark / Light mode toggle  
- 🚩 Priority tagging (Low, Medium, High, Urgent)  
- 💾 Persistent storage using Local Storage  
- 📱 Fully responsive design  

# 🧠 Problem Statement

Most simple to-do apps lack:
- Persistent storage  
- Advanced filtering  
- Interactive UI  

RosePetal solves this by providing a **complete frontend task management system without backend dependency**.

# ⚙️ How It Works

- Tasks are stored using **Local Storage**  
- JavaScript handles:
  - DOM manipulation  
  - Task updates in real-time  
  - Filtering and sorting logic  
- UI is built using **Tailwind CSS + custom styling**  

# ⚡ Key Challenges & Solutions

# 1️⃣ Data Persistence
**Problem:** Tasks were lost on refresh  
**Solution:** Implemented Local Storage to store and retrieve tasks  


# 2️⃣ Dynamic UI Updates
**Problem:** Managing real-time updates  
**Solution:** Used JavaScript DOM manipulation for instant UI rendering  

# 3️⃣ Maintaining Clean UX
**Problem:** Too many features → cluttered UI  
**Solution:** Designed minimal and structured layout with proper spacing  

# 📚 Learning Outcomes

- Building dynamic frontend applications  
- Managing application state without backend  
- Writing structured and scalable JavaScript  
- Designing user-friendly interfaces
