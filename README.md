# RosePetal
# Advanced To-Do List Web Application

A modern, feature-rich task management web application built using HTML, CSS and JavaScript.  
Designed with a premium UI, smooth animations, drag & drop, dark mode, and LocalStorage persistence.

---

## 🚀 Features

### ✅ Core Functionality
- Add, edit, delete tasks  
- Mark tasks as completed  
- Priority levels (Low, Medium, High, Urgent)  
- Due dates  
- Task descriptions  

### 🎛️ Advanced Features
- Drag-and-drop task reordering  
- Search tasks in real-time  
- Filters & sorting options  
- Dark/Light theme toggle  
- LocalStorage saving (data persists after refresh)

### 💎 UI/UX Highlights
- Modern glassmorphism/neumorphism inspired design  
- Smooth animations, transitions, hover effects  
- Responsive layout for mobile, tablet, and desktop  
- Premium, professional interface
